# Painel de Cenário Econômico para Negócios

Pipeline de dados que coleta indicadores econômicos da API do Banco Central, armazena o histórico no PostgreSQL e apresenta informações para tomada de decisão em um dashboard Streamlit.

## Arquitetura

```text
API do Banco Central → Python → PostgreSQL → Streamlit
```

## Indicadores previstos
* Selic
* IPCA
* Dólar Comercial
